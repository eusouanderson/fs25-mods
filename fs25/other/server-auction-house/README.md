## 🇧🇷 Sobre

**Server Auction House** é um sistema de leilões multiplayer em tempo real para o **Farming Simulator 25**.
Jogadores podem criar leilões de veículos, definir preço inicial e duração, e dar lances — tudo sincronizado
entre os clientes e salvo no savegame.

### Funcionalidades
- ✅ Criação de leilões com veículos da sua fazenda
- ✅ Lances em tempo real com notificações no chat
- ✅ Sincronização multiplayer completa (autoritativo no servidor)
- ✅ Persistência no savegame
- ✅ Interface nativa no estilo GIANTS Engine UI
- ✅ Abertura por tecla de atalho (L)

### Como usar
1. Pressione **L** (configurável em *Opções > Controles*) para abrir a casa de leilões
2. Na aba de criação, selecione um veículo, defina preço e duração
3. Confirme para publicar o leilão no servidor
4. Outros jogadores podem dar lances enquanto o leilão estiver ativo
5. Ao encerrar, o vencedor recebe o veículo e o vendedor recebe o valor

### Instalação
1. Baixe o arquivo ZIP abaixo
2. Extraia para `Documentos/My Games/FarmingSimulator2025/mods/`
3. Ative o mod **"Server Auction House"** no menu de mods do jogo/servidor
4. Pronto!

## 🇺🇸 About

**Server Auction House** is a real-time multiplayer auction system for **Farming Simulator 25**.
Players can create vehicle auctions, set a starting price and duration, and place bids — everything
is synchronized across clients and persisted in the savegame.

### Features
- ✅ Create auctions using vehicles from your farm
- ✅ Real-time bidding with chat notifications
- ✅ Full multiplayer synchronization (server-authoritative)
- ✅ Savegame persistence
- ✅ Native GIANTS Engine-styled UI
- ✅ Open with the L key (configurable in *Options > Controls*)

### How to use
1. Press **L** (configurable in *Options > Controls*) to open the auction house
2. In the create tab, select a vehicle, set a price and duration
3. Confirm to publish the auction on the server
4. Other players can place bids while the auction is active
5. When it ends, the winner receives the vehicle and the seller gets paid

### Installation
1. Download the ZIP file below
2. Extract to `Documents/My Games/FarmingSimulator2025/mods/`
3. Enable the **"Server Auction House"** mod in the game/server mod menu
4. Done!
